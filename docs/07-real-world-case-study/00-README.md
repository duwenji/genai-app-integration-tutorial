# 07. Real World Case Study - 実践：既存アプリの統合パターン横断分析

このカテゴリは本チュートリアルの総仕上げです。
01〜06で学んだ呼び出し方式・入出力契約・信頼性/コスト・安全性UX・エージェント型ワークフロー・AIプロダクトUXの原則が、実アプリでどう組み合わさっているかを確認します。

**新しい原則はほとんど登場しません。**
これまでの教材で学んだ設計判断が、どう組み合わさって1つのアプリになっているかに焦点を当てます。

01〜06はそれぞれ独立した1機能の設計を扱う教材でした。
しかし実際のアプリは、1つの画面の裏で複数の設計判断が同時に働いています。
「生成AI活用箇所」とは、アプリの中でLLM（大規模言語モデル）を呼び出している1箇所のことです。
ここでは、実在するアプリ`ai-stock-investing-tutorial`の`app/`を「実アプリ」（教材用の架空コードではなく、実際に動く完成版アプリ）として参照し、01〜06の原則が11箇所の生成AI活用箇所でどう組み合わさっているかを確認します。
はじめて生成AI統合を学ぶ人は、01〜06の内容を細部まで覚えていなくても読み進められるよう、本章の各教材から該当する01〜06章の教材へリンクを張っています。

## 学習目標

- `app/`内11箇所の生成AI活用箇所を、01〜06の観点でマッピングした一覧表を読み解ける
- 01〜06で学んだ設計判断を、自分のアプリの新機能に適用できる
- 運用移行前の確認事項を、チェックリストで一括点検できる
